# Liltbox

[English](README.md) · [简体中文](README.zh-CN.md)

Liltbox 是一款免费的 macOS 应用，把录音整理成通顺对话、简短摘要和本地 Markdown 知识库。录下一段想法，或导入已有音频，在 Mac 上完成整理；能够读取本地文件的 AI Agent 也可以查阅这些内容。

**公开下载准备中。** 当前版本仍处于开发测试阶段，尚未完成 Developer ID 签名、Apple 公证和独立新机测试。本仓库暂未发布安装包，后续下载和更新说明会放在 [Releases](https://github.com/rainbowroy/liltbox/releases)。

## 主要功能

- **录音或导入音频。** 支持导入 M4A、MP3、WAV、WebM、MP4、OGG 和 FLAC。
- **整理对话。** 保留原始识别稿，生成通顺对话、标题、简短描述和附原稿引用的简短摘要。
- **核对与修订。** 可以修订原稿、改名或合并说话人标签、查看版本历史，并重新整理或生成摘要。
- **本机处理。** 转写、说话人标记和摘要生成均在 Mac 上运行；下载所需模型后，可以离线整理。
- **保存为 Markdown。** 自行选择知识库文件夹。能够访问本地文件的 Agent 可以从 `INDEX.md` 开始读取，无需启动 Liltbox。
- **中英文界面。** 界面和 Mac 菜单跟随 macOS 语言设置；切换界面语言不会翻译录音原文或生成内容。

## 系统要求

| 项目 | 当前目标配置 |
| --- | --- |
| Mac | Apple 芯片 |
| macOS | 26 或更新版本 |
| 内存 | 16 GB 及以上 |
| 网络 | 首次下载模型需要联网，下载后可离线整理 |
| 模型 | 约 2.26 GB，在应用内另行下载 |

当前已在 M4 Pro、24 GB 内存的 Mac 上测试；16 GB 设备和独立新机仍待测试。使用者无需安装 Python、Homebrew 或 Chrome。

## 使用方式

以下步骤介绍当前应用的使用流程，公开安装包尚未开放下载。

1. 打开 Liltbox，选择用于保存 Markdown 知识库的文件夹。
2. 在 **模型与保存** 中下载转写、说话人和整理模型。只有你主动选择后才开始下载。
3. 新建会话，主动开始麦克风录音，或导入已有音频。
4. 保存音频，点击 **开始整理**。应用先保存原始识别稿，再生成通顺对话和摘要。
5. 核对整理结果。打开知识库文件夹阅读 Markdown，或让能够访问本地文件的 Agent 查阅。

录音时请保持 Mac 唤醒，不要合盖。录音中断后，可通过 **恢复并保存已有片段** 保存已录下的内容。

## 数据与隐私

录音、原稿和摘要均在本机处理与保存。Markdown 知识库包含 `INDEX.md`、会话文档和版本历史；备份整个知识库文件夹即可保留文字和历史记录。

音频、已下载模型和任务状态另存于 `~/Library/Application Support/Huiyi/`。如果需要同时备份这些内容，请先退出应用，再复制该文件夹。

如果你将知识库交给云端 AI Agent 读取，Agent 可能会把内容发送给对应服务。分享私人资料前，请检查所用 Agent 的设置。

转写和摘要可能出错，重要内容请核对原始录音。说话人标签不代表已确认的真实身份，自然多人会议的识别质量仍在评估。建议在应用内修订文字，以保持知识库归档一致。
